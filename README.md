# CodeForge Strategy OS

CRM-like рабочее пространство для проверки бизнес-гипотез до запуска. Система объединяет pipeline потенциальных клиентов, доказательства по компаниям, расчет unit-экономики, сценарии capacity и Decision Center с логикой Go / No-Go.

## Что реализовано

- **Overview / Control Room** — общий сигнал по доказательствам, CRM и экономике.
- **Companies** — компании, сегмент, город, стадия, приоритет, заметки и активности.
- **Verification** — источники каждого наблюдения, даты, confidence и статусы `unverified`, `in_review`, `verified`, `conflict`, `rejected`, `stale`.
- **Scenarios** — conservative / base / optimistic из единого файла входов.
- **Decision Center** — прозрачные пороги LTV/CAC, payback, delivery load и минимальное число подтвержденных фактов.
- **Документация** — шесть отдельных страниц, доступных через навигацию: AI OS, Operating Model, Product Knowledge Base, Sales Playbook, Upsell Matrix и White Label Playbook.
- **История запусков** — результаты последних расчетов сохраняются в состоянии workspace.

## Единый источник расчетов

`primitives.json` — канонический и версионируемый набор входов. В нем находятся ставки, fixed costs, capacity, продукты, три сценария, benchmark-гипотезы, пороги решения и текстовые правила формул.

Числа из расчетов не дублируются в UI или документации. CRM-данные и доказательства хранятся отдельно от primitives и по умолчанию не смешиваются с неподтвержденными рыночными гипотезами.

## Запуск

Требуется Node.js 18+ и Bun.

```bash
bun install
bun run dev
```

Откройте Vite preview и используйте навигацию приложения. Дев-сервер слушает `0.0.0.0`.

Проверки:

```bash
bun run typecheck
bun test tests/calculations.test.js
```

## Исследовательский dataset

При первом запуске пустого local workspace система загружает воспроизводимый open-web seed из `src/data/researchSeed.ts`: 10 компаний, связанные evidence, ручные задачи и только публичные URL. Источники и числовые наблюдения находятся в `primitives.json`; текущий research pass описан в `RESEARCH_DATASET_2026-08-15.md`.

Seed не маскирует гипотезы под факты: компании имеют статус `in_review`, наблюдения несут `verified` / `partial` / `stale`, а OOH-оценки 109,1 и 114,6 млрд ₽ сохранены как конфликт опубликованных методик. Если workspace уже содержит пользовательские данные, seed их не заменяет.

## Хранение и настройки

Без credentials приложение работает в `local-demo` режиме: состояние CRM сохраняется в `localStorage` браузера. В проекте есть безопасный адаптер Supabase и SQL-схема в `supabase/schema.sql`; для cloud persistence нужно задать `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` через настройки окружения, не записывая секреты в репозиторий.

Внешние API, платежи и авторизация пока не включены намеренно: система сначала должна подтвердить рынок и экономику через реальные источники и оплаченные пилоты.

## Принцип принятия решения

`unverified` не считается доказательством. Сценарий получает флаги, если LTV/CAC, payback, break-even или delivery capacity не проходят пороги из `primitives.json`. Вердикт остаётся условным или `NO-GO`, пока не собран минимальный объем проверяемых данных.
